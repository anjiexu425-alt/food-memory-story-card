# 🍜 Food Memory Story Card（美食记忆故事卡）

> 把一张美食照片，变成一张可以在浏览器里**点击 3D 翻转**的数字手帐记忆卡。

正面是暖白纸张质感的手帐插画 + 6 张故事贴纸 + 3 个英文关键词，背面是一段温暖克制的中文故事文案（带日期、一起吃的人、心情三个可填写空位）。点击卡片任意位置即可翻转，像翻开一页手帐。

这是一个 **DSH（DeepSeek Harness）Skill**：在 DSH 里上传一张美食照片（或直接说"美食故事卡""可翻转卡片""互动故事卡"），它会自动生成一个完整的、自包含的 HTML 文件，保存后双击即可在浏览器里玩。

## ✨ 项目特点

- 🎴 **手帐风格正面**：3:2 横向构图，左侧大插画 + 右侧 6 张贴纸，暖白纸纹、手撕边缘、轻微阴影，温暖怀旧、低饱和哑光质感
- 📖 **故事向背面**：2-4 句温暖中文文案，像手帐里随手写下的话，不煽情；预留「日期 / 一起吃的人 / 心情」填空位
- 🔄 **3D 翻转交互**：纯 CSS 3D transform 实现，点击任意位置翻转，再次点击翻回
- 📱 **全端适配**：手机、平板、电脑均可正常显示
- 🔒 **单文件自包含**：HTML + CSS + JS 全部在一个文件里，正面图以 base64 嵌入，不依赖任何外部链接，离线可用

## 🔧 安装方法（DSH Skill）

### 方式一：直接复制（推荐）

把本仓库的 `SKILL.md` 复制到 DSH 的 skills 目录：

```bash
mkdir -p ~/.dsh/skills/food-memory-story-card
cp SKILL.md ~/.dsh/skills/food-memory-story-card/
```

重启 / 刷新 DSH 会话，技能即可生效，之后直接对 DSH 说"帮我做一张美食故事卡"或上传美食照片。

### 方式二：克隆整个仓库

```bash
git clone https://github.com/anjiexu425-alt/food-memory-story-card.git
cd food-memory-story-card
mkdir -p ~/.dsh/skills/food-memory-story-card
cp SKILL.md ~/.dsh/skills/food-memory-story-card/
```

## 🎮 使用方法

1. 在 DSH 里**上传一张美食照片**，或直接说"给我做一张美食故事卡"；
2. Skill 会分析照片：识别主菜、情绪、核心视觉锚点；
3. 生成**正面插画描述**（暖白纸、哑光水粉 / 剪纸感、低饱和、温暖怀旧）；
4. 挑选正好 **6 个故事向贴纸元素** + **3 个英文关键词**；
5. 撰写背面**中文故事文案**（60-100 字，含日期 / 一起吃的人 / 心情填空位）；
6. 输出一张完整的**可点击翻转 HTML 卡片**；
7. 把代码保存为 `美食记忆故事卡.html`，用浏览器打开即可点击翻转。

## 🧩 交互玩法

- 生成透明贴纸页（可打印贴纸）

- 导出为分享图 / PDF

## 🛠 技术细节

- 纯前端：`HTML + CSS + JS`，无任何依赖
- 翻转交互：CSS `transform-style: preserve-3d` + `rotateY(180deg)`
- 图片嵌入：base64 data URI，完全离线可用
- 响应式：`clamp()` / 百分比 + `@media` 适配移动端
