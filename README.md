# 🍜 Food Memory Story Card（美食记忆故事卡）

> 把一张美食照片，变成一张可以在浏览器里**点击 3D 翻转**的数字手帐记忆卡。

正面是暖白纸张质感的手帐插画 + 6 张故事贴纸 + 3 个英文关键词，背面是一段温暖克制的中文故事文案（带日期、一起吃的人、心情三个可填写空位）。点击卡片任意位置即可翻转，像翻开一页手帐。

这是一个 **DSH（DeepSeek Harness）Skill**：在 DSH 里给一张美食照片的本地文件路径或图片链接、或用文字描述一道菜（或直接说"美食故事卡""可翻转卡片""互动故事卡"），它会自动生成一个完整的、自包含的 HTML 文件，保存后双击即可在浏览器里玩。

> 💡 DSH 的网页界面不支持直接上传图片，且部分模型没有视觉能力。Skill 会先探测宿主能力再自动分流：能读图就 `read_image` 观察照片；不能读图就改用你的文字描述；能生图就生成手帐风正面图并嵌入，不能生图就用 inline SVG 手绘插画。详见下方「能力分流」。

## ✨ 项目特点

- 🎴 **手帐风格正面**：3:2 横向构图，左侧大插画 + 右侧 6 张贴纸，暖白纸纹、手撕边缘、轻微阴影，温暖怀旧、低饱和哑光质感
- 📖 **故事向背面**：2-4 句温暖中文文案，像手帐里随手写下的话，不煽情；预留「日期 / 一起吃的人 / 心情」填空位
- 🔄 **3D 翻转交互**：纯 CSS 3D transform 实现，点击任意位置翻转，再次点击翻回
- 🧭 **能力自动分流**：按宿主「能否读图 / 能否生图 / 能否取到生成图」三项能力，自动走主路径或降级路径，任何降级都会如实告知
- 📱 **全端适配**：手机、平板、电脑均可正常显示
- 🔒 **单文件自包含**：HTML + CSS + JS 全部在一个文件里，正面图以 base64 或 inline SVG 内联，不依赖任何外部链接，离线可用

## ⚙️ 能力分流

产品主目标：在具备**视觉理解 + 图像生成**能力的宿主（如 ChatGPT、豆包）中，用户上传美食照片后，直接得到「手帐风正面图 + 背面记忆故事 + 可翻转 HTML」。

Skill 开始工作前先探测三项能力：

| 能力开关 | 含义 |
| --- | --- |
| `can_read_images` | 宿主能否理解图片内容（视觉理解） |
| `can_generate_images` | 宿主能否生成图片（图像生成工具） |
| `can_access_generated_image` | 能否拿到生成图片的可嵌入内容（文件路径 / base64） |

### 主路径（三项能力全部可用）

```
照片 → 视觉分析（read_image 观察原图）
     → 生成手帐风正面图（图像生成工具）
     → 获取生成图片（文件路径 / base64）
     → base64 嵌入 HTML
     → 背面故事文案
     → 可翻转 HTML
```

### 降级路径（能力不足时自动切换）

| 触发场景 | 降级策略 | 禁止事项 |
| --- | --- | --- |
| 无视觉 | 明示无法读图，改用用户文字描述构建画面 | 禁止假装看过照片、编造照片细节 |
| 无生图 | 改用 inline SVG / CSS 手绘手帐视觉 | 禁止引用不存在的图片或外部链接 |
| 生图成功但取不到文件 | 改用 SVG fallback，或把图片与 HTML 分开交付并明确告知 | 禁止虚报「图片已嵌入」、假 base64 |

**诚实原则**：任何降级都会向用户明确说明走的是哪条路径、为什么，绝不静默降级或假装能力存在。

## 🔧 安装方法（DSH Skill）

### 方式一：直接复制（推荐）

把本仓库的 `SKILL.md` 复制到 DSH 的 skills 目录：

```bash
mkdir -p ~/.dsh/skills/food-memory-story-card
cp SKILL.md ~/.dsh/skills/food-memory-story-card/
```

重启 / 刷新 DSH 会话，技能即可生效，之后直接对 DSH 说"帮我做一张美食故事卡"、给一个图片路径 / 链接，或用文字描述一道菜。

cd food-memory-story-card
mkdir -p ~/.dsh/skills/food-memory-story-card

## 🎮 使用方法

1. 在 DSH 里**给一张美食照片的本地路径或图片链接**，或用文字描述一道菜；也可以直接说"给我做一张美食故事卡"；
2. Skill **先探测宿主能力**（能否读图 / 生图 / 取图），再按能力分流获取食物画面；
3. 识别主菜、情绪、核心视觉锚点；
4. 生成**正面插画描述**（暖白纸、哑光水粉 / 剪纸感、低饱和、温暖怀旧）；
5. 挑选正好 **6 个故事向贴纸元素** + **3 个英文关键词**；
6. 撰写背面**中文故事文案**（60-100 字，含日期 / 一起吃的人 / 心情填空位）；
7. 按能力生成正面视觉（能生图则生成并嵌入；否则 inline SVG 手绘），输出一张完整的**可点击翻转 HTML 卡片**；
8. 把代码保存为 `美食记忆故事卡.html`，用浏览器打开即可点击翻转。

## 🛠 技术细节

- 纯前端：`HTML + CSS + JS`，无任何依赖
- 翻转交互：CSS `transform-style: preserve-3d` + `rotateY(180deg)`
- 图片嵌入：base64 data URI（主路径）或 inline SVG（降级路径），完全离线可用
- 响应式：`clamp()` / 百分比 + `@media` 适配移动端
